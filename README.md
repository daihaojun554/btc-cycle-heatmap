# BTC 月度涨跌 & 四年周期热力图

用 GitHub 贡献格子图的方式看比特币 13 年的历史，提供**两个视图**（顶部标签切换）：

## 视图一：月度涨跌热力图（默认）

- 每格 = **1 个月**，颜色 = **该月相对上个月的涨跌幅**（本月收盘 vs 上月收盘）
  - 深绿 = 大涨，浅绿 = 小涨，浅红 = 小跌，深红 = 大跌
  - 用**对称对数刻度**映射：±5% 和 ±50% 的视觉强度对称，避免个别极端月份（如 2013-11 的 +309%）把其余格子压平
- **四年周期用外框框出**：每 4 行（4 年）一个带边框的区块，当前周期用橙色高亮
- **每个周期内部有阶段色带**：上涨期 → 顶部区 → 下跌期 → 盘整期，标注顶/底位置，当前阶段用白框圈出
- 左侧年份标签显示该年涨跌与涨跌月数
- **当月格子**用实时价对比上月收盘，带虚线斜纹并标注「进行中」
- 悬停显示：本月收盘、上月收盘、涨跌幅、月内最高/最低

## 四年周期与阶段

「四年周期」按**自然四年**切分，边界整齐、与「一年一行」对齐：

| 周期 | 区间 | 顶部 | 底部 |
|---|---|---|---|
| 1 | 2013–2016 | 2013-11 $4,000 | 2015-01 $175 |
| 2 | 2017–2020 | 2017-12 $19,660 | 2018-12 $3,120 |
| 3 | 2021–2024 | 2021-04 $64,900 | 2022-11 $15,470 |
| 4 | **2025–2028（当前）** | **2025-10 $126,198** | **2026-06 $57,740** |

每个周期内部划分为四个阶段：

| 阶段 | 含义 | 操作提示 |
|---|---|---|
| 🟢 上涨期 | 周期启动上行 | 可持有，不宜追高 |
| 🔴 顶部区 | 估值最贵，历史见顶区间 | 建议分批止盈 |
| 🟥 下跌期 | 见顶回落，估值压缩 | 观望等待 |
| 🔵 盘整期 | 底部横盘 | 通常是布局下一轮的窗口 |

**顶/底怎么定位的**：采用「评分锚点 + 价格确认」——
先用周期估值评分找到最贵/最便宜的时刻（评分反映估值，能穿越价格噪声），
再在该时刻 ±3 个月内取价格极值作为实际点位。

之所以不能纯用价格极值：自然四年的切分与真实周期存在错位，例如「2017-2020」段里
价格最高点在 2020 年末，但那不是周期顶（真正的顶是 2017-12），必须以评分为锚才能选对。

**当前状态**（页面顶部横幅实时显示）：2025–2028 周期，第 21/48 个月，进度 43.8%，
处于**盘整期**。

## 视图二：周期估值热力图

- 每格 = **1 周**，按 4 次减半周期分段
- 颜色 = **周期性价比评分**（0-100），衡量「此刻贵不贵」而非涨跌幅
- 自动标注历史周期顶底（★），买点绿框、卖点红框

### 周期评分构成

| 维度 | 权重 | 含义 |
|---|---|---|
| 距 ATH 回撤 | 40% | 回撤越深越接近底部 |
| 幂律趋势偏离 | 35% | 相对长期对数趋势线的高估/低估 |
| Mayer Multiple | 25% | 价格 / 200 日均线 |

评分区间：`0-12` 极度低估 · `12-25` 明显低估 · `25-40` 偏低估 · `40-55` 中性 ·
`55-70` 偏高 · `70-85` 高估 · `85-100` 极度高估

信号识别要求「价格是 ±26 周窗口内的极值」**且**「评分处于极端区间」，避免把中性波动误报成买卖点。

## 其他功能

- **实时数据**：服务每小时自动抓取最新价格并重算，前端每 5 分钟轮询
- **减半周期进度**：按实时区块高度计算当前周期走到哪一步，预测下次减半时间
- **价格走势图**：对数坐标，背景色带反映周期评分
- **月度统计**：胜率、中位数、最强/最弱月份、连续同向月数

## 快速开始

零第三方依赖，只需 Node.js 18+（用到内置 `fetch`）。

```bash
node server/index.js
```

打开 http://127.0.0.1:8787

手动刷新一次数据（不启动服务）：

```bash
node server/update.js
```

### 环境变量

| 变量 | 默认值 | 说明 |
|---|---|---|
| `PORT` | `8787` | 监听端口 |
| `HOST` | `127.0.0.1` | 监听地址，部署时设 `0.0.0.0` |
| `UPDATE_INTERVAL_MS` | `3600000` | 更新间隔（默认 1 小时） |

## 接口

| 路径 | 说明 |
|---|---|
| `GET /api/snapshot` | 完整快照：周线 + 月度序列 + 评分 + 信号 + 减半周期 |
| `GET /api/status` | 服务状态、数据新鲜度、下次更新倒计时 |
| `POST /api/refresh` | 手动触发一次更新 |

`/api/snapshot` 的关键字段：

- `monthly[]` — 月度序列，每项含 `key`(2026-09)、`close`、`prevClose`、`changePct`、`isPartial`
- `monthlyStats` — 月度汇总（胜率、中位数、极值月份等）
- `cycles[]` — 四年周期，每项含 `label`、`top`、`bottom`、`phases[]`、`currentPhaseId`、`isCurrent`
- `currentCycle` — 当前周期（含 `progress`：elapsed/total/pct/remain）
- `points[]` — 周线 + 周期评分
- `signals[]` — 周期顶底信号
- `halving` — 减半周期进度
- `spot` — 实时价

```
btc-cycle-heatmap/
├── server/
│   ├── fetch.js     数据抓取（周线 / 日线分页 / 实时价 / 区块高度）+ 月度聚合
│   ├── analyze.js   周期估值评分算法与顶底信号识别
│   ├── cycles.js    四年周期切分与阶段划分
│   ├── update.js    数据管线（抓取 → 分析 → 原子落盘）
│   └── index.js     HTTP 服务 + 每小时定时更新
├── public/
│   ├── index.html   页面结构（周期横幅 + 两个视图 + 标签切换）
│   ├── style.css    样式

└── data/
    ├── snapshot.json  最新快照（前端数据来源）
    └── history.jsonl  历史快照记录
```

## 数据源

- **周线**：Kraken 公开 OHLC API，BTC/USD 全历史（2013-10 至今，677 周）
- **日线**：Binance 公开 K线，分页拉全量（2017-08 至今），用于精确聚合自然月
- **月度拼接**：日线覆盖期内用日线聚合（月末即月末）；更早的 2013-2017 用周线聚合补全，共 156 个月
- **区块高度**：blockstream.info → blockchain.info → mempool.space 依次容错
- 所有接口均为公开免费、无需 API Key

网络全部失败时会保留旧缓存并在页面上标注「数据源暂时不可用」，不会白屏。

## 部署

### 方式一：GitHub Pages（纯静态，推荐）

页面可完全静态托管。历史数据由 GitHub Actions 每小时烘焙成 `public/data.json`，
实时价格由浏览器直接向交易所公开接口获取（这些接口允许跨域）。

→ 详细步骤见 **[DEPLOY.md](./DEPLOY.md)**

### 方式二：本地 / 服务器直接跑

```bash
HOST=0.0.0.0 PORT=8080 node server/index.js
```

### 方式三：systemd（Linux 服务器）

```ini
[Unit]
Description=BTC Cycle Heatmap
After=network.target

[Service]
Type=simple
WorkingDirectory=/opt/btc-cycle-heatmap
ExecStart=/usr/bin/node server/index.js
Environment=HOST=0.0.0.0
Environment=PORT=8080
Restart=always
RestartSec=5
User=www-data

[Install]
WantedBy=multi-user.target
```

### 方式四：PM2

```bash
pm2 start server/index.js --name btc-heatmap
pm2 save
```

### 两种运行模式

前端会自动探测环境，同一份代码本地和线上都能跑：

| | 本地服务模式 | 静态托管模式 |
|---|---|---|
| 历史数据 | `/api/snapshot` | `public/data.json` |
| 实时价格 | `/api/price`（服务端抓取） | 浏览器直连交易所 |
| 探测方式 | 优先请求 API | API 返回 404 时自动回退 |
